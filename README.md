# n8n workflow

Put the exported workflow here as `workflow.json`:

1. Open the workflow "BUAN6385 - Ticket Triage & Escalation (starter)" in n8n.
2. Click the `...` menu next to the workflow name, choose **Download**.
3. Rename the file to `workflow.json` and upload it into this folder on GitHub.

The web app (`/api/_engine.js`) implements the same nodes in the same order, so a grader
can compare the canvas to the code node by node.
